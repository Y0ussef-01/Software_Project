🏭 إيه هو MPI؟

MPI = Message Passing Interface — يعني بروتوكول بيخلي برامج كتير تشتغل في نفس الوقت وتتكلم مع بعض بالرسائل.

تخيل مصنع فيه مدير ومجموعة موظفين. المدير بيوزع الشغل على الموظفين، كل واحد بيشتغل في الجزء بتاعه، وبعدين بيرجعوا النتيجة للمدير. ده بالضبط اللي بيحصل في MPI.

🧑‍💼 Process 0 (المدير)
↔
👷 Process 1
↔
👷 Process 2
↔
👷 Process 3

📌 أهم 4 مفاهيم لازم تعرفهم

المفهومالمعنىتشبيه
Rank رقم الـ Process — زي رقم الموظف رقم الباج اللي عليه الموظف
Size إجمالي عدد الـ Processes اللي شغالة عدد الموظفين في المصنع
MPI_COMM_WORLD القناة اللي الكل بيتكلم عليها جروب الواتساب اللي فيه الكل
Tag رقم تعريفي للرسالة عشان ميتشالش رسالة غلط الرقم اللي بتكتبه على الجواب

🔁 هيكل أي برنامج MPI

template.cpp 
MPI_Init(&argc, &argv);         // 1. الأول دايماً

MPI_Comm_rank(MPI_COMM_WORLD, &rank);  // 2. اعرف رقمك
MPI_Comm_size(MPI_COMM_WORLD, &size);  // 3. اعرف الكل كام

// 4. الشغل الحقيقي هنا

MPI_Finalize();                         // 5. الآخر دايماً

⚠️ قاعدة ذهبية: MPI_Init أول سطر، MPI_Finalize آخر سطر — دايماً بدون استثناء!

Quiz 1 — المدير والموظفين الفردي/الزوجي

أول برنامج: كل Process بتعرف دورها
quiz1.cpp 
#include <mpi.h>
#include <stdio.h>

int main(int argc, char** argv) {
    int world_rank;

    MPI_Init(&argc, &argv);
    MPI_Comm_rank(MPI_COMM_WORLD, &world_rank);

    if (world_rank == 0) {
        printf("My master node (Rank %d)\n", world_rank);
    } 
    else if (world_rank % 2 == 0) {
        printf("My even worker node (Rank %d)\n", world_rank);
    } 
    else {
        printf("My odd worker node (Rank %d)\n", world_rank);
    }

    MPI_Finalize();
    return 0;
}
السطرالشرح بالعامية
MPI_Init(&argc, &argv) 🔑 افتح بيئة MPI — زي ما تقول "يلا الكل يحضر"
MPI_Comm_rank(..., &world_rank) 🏷️ كل Process بتسأل "أنا رقم كام؟" — الجواب يتحط في world_rank
if (world_rank == 0) 👑 لو أنا المدير (رقم 0)، اطبع "master"
world_rank % 2 == 0 🔢 لو رقمي زوجي (2، 4، 6...) اطبع "even worker"
else 🔢 الباقي (1، 3، 5...) اطبع "odd worker"
MPI_Finalize() 🔒 سكر بيئة MPI — زي "الكل يمشي"

🎯 الفكرة الأساسية: البرنامج ده بيتشغل على كل Process في نفس الوقت، بس كل واحد بيتصرف حسب رقمه. الكود واحد، السلوك مختلف.

Quiz 6 — إيجاد الأعداد الأولية

نفس فكرة التقسيم + دالة isPrime
quiz6.cpp 
bool isPrime(int n) {
    if (n <= 1) return false; // 0 و 1 مش أعداد أولية
    for (int i = 2; i < n; i++) {
        if (n % i == 0) return false; // لو انقسم على حاجة → مش أولي
    }
    return true; // لو ماحدش قسمه → أولي
}

// في main:
for (int i = start_num; i <= end_num; i++) {
    if (isPrime(i)) {
        message += NumberToString(i) + " "; // اضيفه للرسالة
        primes_count++;
    }
}

if (primes_count == 0) {
    message += "None"; // لو مفيش أعداد أولية
}
الجزءالشرح
isPrime(n) دالة بتشيك: الرقم n عدد أولي ولا لأ؟ بتجرب تقسمه على كل حاجة من 2 للـ n-1
NumberToString(i) بتحول الرقم لـ string عشان نضمه في الرسالة (زي to_string)
message += ... بنبني string طويل فيه كل الأعداد الأولية اللي لقيناها
primes_count == 0 لو Process دي ملقتش أي عدد أولي في نطاقها، تطبع "None"

MPI_Send و MPI_Recv — إرسال واستقبال

mpi1.cpp (الشرح) — التواصل المباشر بين Processes

📮 تخيل الموضوع كده

MPI_Send = بعت جواب بريدي

MPI_Recv = فتحت الجواب واتسلمت محتواه

لازم الاتنين يوجدوا — لو بعت ومفيش حد بيستقبل، البرنامج بيوقف وينتظر للأبد!

mpi1.cpp (send/recv example) 
// في Process 0 (المُرسل):
double a[100];
for(int i = 0; i < 100; i++) a[i] = 2.5;

MPI_Send(a,          // 1. البيانات اللي بنبعتها
          100,        // 2. كم عنصر
          MPI_DOUBLE, // 3. نوع البيانات
          1,          // 4. الـ Rank اللي بنبعتله
          17,         // 5. الـ Tag (رقم تعريفي)
          MPI_COMM_WORLD); // 6. القناة

// في Process 1 (المُستقبل):
double received_data[100];

MPI_Recv(received_data, // 1. هنحط البيانات فين
          100,           // 2. أقصى عدد عناصر
          MPI_DOUBLE,    // 3. نوع البيانات
          0,             // 4. بنستقبل من مين
          17,            // 5. نفس الـ Tag
          MPI_COMM_WORLD,
          &status);      // 6. معلومات عن الرسالة
الباراميترفي Sendفي Recv
1عنوان البيانات اللي بنبعتهاالمكان اللي هنحط فيه البيانات
2عدد العناصرأقصى عدد عناصر ممكن تستقبل
3نوع البياناتنفس النوع لازم يبقى متطابق
4الـ Destination (بنبعت لمين)الـ Source (بنستقبل من مين)
5الـ Tagنفس الـ Tag لازم يتطابق

⚠️ تنبيه مهم: العدد، النوع، والـ Tag لازم يكونوا متطابقين في Send و Recv. لو اختلفوا، هتحصل مشكلة!

💡 اختصار مفيد: بدل ما تكتب رقم معين في Recv، ممكن تستخدم MPI_ANY_SOURCE و MPI_ANY_TAG عشان تستقبل من أي حد بأي tag.

mpi2.cpp — جمع النتائج يدوياً بـ Send/Recv

قبل ما نتعلم MPI_Reduce، ده الأسلوب اليدوي
mpi2.cpp 
// 1. كل process تحسب جزئها
startval = n * mynode / totalnodes + m;
endval   = n * (mynode + 1) / totalnodes;

for(int i = startval; i <= endval; i++)
    sum += i;

// 2. كل موظف يبعت ناتجه للمدير
if(mynode != 0) {
    MPI_Send(&sum, 1, MPI_INT, 0, 1, MPI_COMM_WORLD);
} else {
    // المدير يستقبل من الكل ويجمع
    for(int j = 1; j < totalnodes; j++) {
        MPI_Recv(&accum, 1, MPI_INT, j, 1, MPI_COMM_WORLD, &status);
        sum += accum;
    }
}

→
Process 0 يجمع الكل
←
Worker 2 → sum جزئي

mpi3.cpp — MPI_Bcast (الإذاعة)

المدير بيبعت نفس القيمة لكل الـ Processes دفعة واحدة

📻 التشبيه: راديو الإذاعة

زي المذيع في الراديو — Process 0 بيقول الرسالة مرة واحدة، والكل يسمعها في نفس الوقت.

مش محتاج تعمل Send لكل واحد لوحده!

mpi3.cpp 
int shared_value = 0; // الكل بيبدأ بـ 0

if (rank == 0) {
    shared_value = 500; // المدير بس بيغير القيمة
}

// ده لازم ينفذ من الكل (مش في if!)
MPI_Bcast(
    &shared_value,  // القيمة اللي هنذيعها
    1,              // عدد العناصر
    MPI_INT,        // النوع
    0,              // مين اللي بيذيع (rank 0)
    MPI_COMM_WORLD
);

// بعد السطر ده، الكل عنده shared_value = 500

⚠️ مهم جداً: MPI_Bcast لازم تتكتب بره الـ if — الكل (مدير وموظفين) لازم ينفذ السطر ده. لو حطيتها جوه if للـ rank 0 بس، البرنامج هيوقف وينتظر!

mpi4.cpp — MPI_Reduce (التجميع)

كل الـ Processes بتبعت قيمة، والمدير بيعمل عليهم عملية

🧮 التشبيه: الاستمارة الجماعية

كل موظف بيملي استمارة بنتيجته، والمدير بياخد كل الاستمارات ويجمعهم (أو يجيب أكبرهم، أو أصغرهم، إلخ).

mpi4.cpp 
int local_value = rank * 10; // كل process عندها قيمة مختلفة
int global_sum = 0;

MPI_Reduce(
    &local_value,  // 1. قيمتي الخاصة
    &global_sum,   // 2. الناتج (عند المدير)
    1,             // 3. عدد العناصر
    MPI_INT,       // 4. النوع
    MPI_SUM,       // 5. العملية (الجمع)
    0,             // 6. مين يستقبل الناتج
    MPI_COMM_WORLD
);
عملية MPI_Reduceالمعنىمثال
MPI_SUMجمع كل القيم0+10+20+30 = 60
MPI_MAXأكبر قيمةmax(0,10,20,30) = 30
MPI_MINأصغر قيمةmin(0,10,20,30) = 0
MPI_PRODضرب كل القيم0×10×20×30 = 0

📌 Task 1 — حساب π بطريقة Leibniz

المعادلة: π = 4 × (1 - 1/3 + 1/5 - 1/7 + ...)

task1.cpp — الخطوات 
// 1. المدير يقرأ N ويذيعه للكل
if (rank == 0) cin >> N;
MPI_Bcast(&N, 1, MPI_INT, 0, MPI_COMM_WORLD);

// 2. كل process تحسب جزئها
for (int i = startval; i < endval; i++) {
    double term = 1.0 / (2.0 * i + 1.0);
    if (i % 2 != 0) term = -term; // الفردي بالسالب
    partial_sum += term;
}

// 3. جمع كل الأجزاء عند المدير
MPI_Reduce(&partial_sum, &total_sum, 1, MPI_DOUBLE, MPI_SUM, 0, MPI_COMM_WORLD);

// 4. المدير يحسب π
if (rank == 0) pi = 4.0 * total_sum;

📌 Task 5 — Normalization + MPI_Gather

بنعمل تطبيع للبيانات (نحطها بين 0 و1)، ثم نجمع كل النتائج عند المدير.

task5.cpp — الخطوات 
// 1. إيجاد Min و Max عالمي
MPI_Reduce(&local_min, &global_min, 1, MPI_DOUBLE, MPI_MIN, 0, ...);
MPI_Reduce(&local_max, &global_max, 1, MPI_DOUBLE, MPI_MAX, 0, ...);

// 2. إذاعة Min و Max للكل
MPI_Bcast(&global_min, 1, MPI_DOUBLE, 0, ...);
MPI_Bcast(&global_max, 1, MPI_DOUBLE, 0, ...);

// 3. كل process تعمل Normalization
normalized[i] = (data[i] - global_min) / (global_max - global_min);

// 4. MPI_Gather: كل الـ processes بتبعت نتيجتها للمدير
MPI_Gather(local_normalized, local_N, MPI_DOUBLE,
           global_normalized, local_N, MPI_DOUBLE,
           0, MPI_COMM_WORLD);
الدالةهي إيه؟

Cheatsheet — ملخص كل الدوال

مرجع سريع لكل دالة MPI اتعملت في الملفات
الدالة بتعمل إيه؟ اتاستخدمت في
MPI_Init() بدء بيئة MPI — الأول دايماً كل الملفات
MPI_Finalize() إنهاء بيئة MPI — الآخر دايماً كل الملفات
MPI_Comm_rank() كل process تعرف رقمها (rank) كل الملفات
MPI_Comm_size() كل process تعرف الإجمالي (size) quiz3, mpi2, tasks
MPI_Send() بعت بيانات لـ Process معينة mpi1, mpi2, task4
MPI_Recv() استقبلت بيانات من Process معينة mpi1, mpi2, task4
MPI_Bcast() الـ Root يبعت نفس القيمة للكل mpi3, task1, task3, task5, quiz.cpp
MPI_Reduce() كل الـ Processes بتبعت، والـ Root بيعمل عملية (SUM, MAX, MIN) mpi4, tasks, quiz.cpp
MPI_Gather() كل Process بتبعت جزئها، الـ Root بيرصهم بالترتيب task5
